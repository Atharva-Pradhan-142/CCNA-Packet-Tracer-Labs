# CCNA Packet Tracer Labs

A collection of network topologies built and tested in Cisco Packet 
Tracer while preparing for CCNA certification — covering VLANs, 
inter-VLAN routing, OSPF, DHCP, NAT, ACLs, port security, and SSH 
hardening.

## Labs

| # | Lab | Topics |
|---|-----|--------|
| 01 | [Router-on-a-Stick Multi-Router DHCP](./01-router-on-a-stick-multi-router-dhcp) | Router-on-a-Stick, trunking, inter-VLAN routing, DHCP |
